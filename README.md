# Enterprise DevSecOps CI/CD Platform

A reusable pipeline pattern implementing validation, testing, secret scanning, IaC scanning, container scanning, SBOM creation and release evidence.

## Quality gates

1. YAML validation
2. Secret scanning
3. Dockerfile linting
4. Infrastructure security
5. Build
6. Functional test
7. Vulnerability threshold
8. SBOM
9. Artifact evidence

The repository contains no application business logic.
